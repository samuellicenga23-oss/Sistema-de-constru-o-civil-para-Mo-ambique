Parte A — Preparação (só na 1.ª vez)

1 Abrir o PowerShell na pasta do projecto

Terminal Cursor → painel Terminal · ou PowerShell do Windows

Set-Location "C:\Users\Expert Sam\Documents\MediObra"

Confirme que está na raiz (deve ver pastas apps, packages, package.json).

2 Instalar dependências Node

Terminal na raiz MediObra

npm install

Instala web, API e pacote shared. Correr de novo depois de um git pull grande.

3 Criar o ficheiro de configuração da API

Terminal na raiz:

Copy-Item apps\api\.env.example apps\api\.env

Ficheiro abrir e editar:

apps\api\.env

Valores mínimos recomendados para local:

DATABASE_URL=postgres://postgres:SUA_PASSWORD@localhost:5432/sigo
PORT=4100
NODE_ENV=development
FRONTEND_URL=http://127.0.0.1:5273
PLANT_SERVICE_URL=http://127.0.0.1:8001
SESSION_COOKIE_SECRET=segredo-local-qualquer
CORS_ORIGIN=

Substitua SUA_PASSWORD pela password real do utilizador PostgreSQL.

4 Criar a base de dados PostgreSQL

PostgreSQL serviço Windows do Postgres a correr · depois no Terminal:

psql -U postgres -c "CREATE DATABASE sigo;"

Se a base já existir, ignore o erro “already exists”.

5 Migrar e popular a base

Terminal na raiz MediObra:

npm run db:migrate
npm run db:seed

Cria as tabelas e carrega catálogo/composições/zonas de preços.

6 Criar o primeiro utilizador administrador

Terminal na raiz:

npm run bootstrap:admin -- --name "Admin" --email admin@local.test --password "ATuaPasswordForte"

Guarde este email e password — são os dados de login no browser.

7 (Opcional) Preparar o leitor de plantas Python

Terminal pasta do serviço:

Set-Location "C:\Users\Expert Sam\Documents\MediObra\apps\plant-service"

Parte B — Arrancar o localhost (todos os dias)

Abra 2 ou 3 terminais no Cursor (ícone “+” no painel Terminal). Cada serviço fica num terminal separado e deve ficar a correr.

8 Terminal 1 — API (backend)

Terminal 1 pasta raiz MediObra

Set-Location "C:\Users\Expert Sam\Documents\MediObra"
npm run dev:api

Deixe este terminal aberto. Quando estiver bem: responde em http://127.0.0.1:4100.

9 Terminal 2 — Frontend (web)

Terminal 2 pasta raiz MediObra

Set-Location "C:\Users\Expert Sam\Documents\MediObra"
npm run dev:web

Deixe este terminal aberto. A app fica em http://127.0.0.1:5273.

10 Terminal 3 — Leitor de plantas (opcional)

Terminal 3 pasta raiz:

Set-Location "C:\Users\Expert Sam\Documents\MediObra"
npm run dev:plant

Porta 8001. Se não precisar de plantas PDF, pode saltar este passo.

Parte D — Problemas comuns

  • Porta 5273 ocupada — feche outro Vite antigo; a porta é estrita (strictPort).
  • API não liga — confira PostgreSQL a correr e o DATABASE_URL em apps\api\.env.
  • Login falha — confirme que correu o bootstrap:admin; conta inactiva não entra.
  • Plantas falham — Terminal 3 tem de estar com npm run dev:plant.
  • Não use a porta 4100 no browser para a UI — use sempre 5273 em desenvolvimento (o Vite faz proxy do /api).
